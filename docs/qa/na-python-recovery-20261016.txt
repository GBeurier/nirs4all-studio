Defects corrected
* Missing Y and metadata values use the same preserving defaults for new
  imports and saved configurations. Explicit abort/drop/replace policies stay
  explicit. Legacy policy spellings are normalized at the library boundary.
* IO preserves physically blank single-column records under preserving NA
  policies. Categorical missing targets remain missing instead of becoming
  an extra category. SDK target distributions exclude missing class labels.
* Python selection is saved atomically with recovery from the previous valid
  settings file. A failed save or activation retains the previous selection.
* Cold inventory probes retry once after a timeout. Detection caches include
  the selection context. An unavailable health request does not imply that an
  environment needs to be installed.
* Reused environments report installed/required versions separately from
  absent packages. Updates prepare the selected environment in place. An
  existing managed venv is never erased by the create-environment action.
* A Studio version change alone does not restart onboarding for a verified
  environment whose setup was already completed.
* uv's installer-owned dist-info/uv_cache.json no longer produces a false SDK
  tampering error. Package code and similarly named files inside the SDK
  remain attested. Deliberately changed code is still refused.
* Optional environment-size diagnostics have a time budget and a short cache.
